playren

A browser-based renju game room. Join the same room with a room code for 2-player games or pair renju. Others can spectate.

How a game goes

  1. Enter the room
    Matching room codes connect to the same room.
  2. Take a seat
    Click an open seat. Click the spectator area to return to watching.
  3. Ready up
    When everyone clicks their seat to become Ready, the game starts automatically.
  4. Play
    Games open with Taraguchi-10. Each move adds increment time (Fischer rules).
  5. Game end & review
    Games end by resignation, agreed draw, or timeout. Review follows the game.

Room settings

Changeable by anyone when no game is in progress. Changes are announced to everyone.

  • Time settings (base minutes + increment seconds)
  • Swap seat colors (if not swapped manually, Black and White alternate automatically)
  • Pair renju ON/OFF
  • Reset seats (everyone returns to spectating)

During a game

  • Draw offers, takebacks, resignation
  • Position navigation (<<, <, latest, >, >>; arrow keys supported)
  • Find the last move (press "latest" to briefly highlight it)
  • Chat
  • Move confirmation (when ON, two clicks to play a move)

Display options

From the eye menu (bottom right). Settings saved on device.

  • Language and appearance
  • Sound ON/OFF
  • Coordinates and move numbers ON/OFF
  • Board color and stone shading

Notes

  • Reconnection supported (disconnected names turn gray; clocks keep running)
  • On phones, "Add to Home Screen" launches playren like an app
