playren

playren is a browser-based Renju game room for regular two-player games or four-player Pair Renju. Other participants can watch.

Game Flow

  1. Enter a room
    Enter your display name and room code. The same room code connects users to the same room.
  2. Take a seat
    Click an empty seat to take it. Pair Renju provides upper and lower seats on both teams. Click the spectator area to return to the spectator seats.
  3. Mark ready
    Each seated player clicks their own seat to mark ready. The game starts automatically when everyone is ready.
  4. Opening (Taraguchi-10)
    The opening follows Taraguchi-10. During the opening, Swap choices and Black's Choice branch with 10 candidate moves may appear.
  5. Play the game
    After each move, time is added to the player's clock using Fischer timing.
  6. End and post-game review
    The game ends by timeout, resignation, or agreed draw. After the game, you can review the move sequence and copy a RenjuPortal final-position kifu link from the end message in chat.

Main Features

  • Two-player games or four-player Pair Renju, plus spectator seats
  • An underlined player name indicates the host
  • The host can:
    • Set the clock (base minutes + increment seconds, with time handicap)
    • Swap colors before a game
    • Enable or disable Pair Renju
  • Chat with comments
  • Draw offers, takebacks, and resignation
  • Position navigation (<<, <, Latest, >, >>, with arrow-key support)
  • Post-game review after the game ends
  • Kifu copy after the game ends from the chat end message, using a RenjuPortal final-position link
  • Display settings: language, sound, coordinates, board color, and move numbers
  • Move confirmation: when enabled, the first tap shows a candidate ring and the second tap plays the move.
  • Reconnect support: a disconnected player is greyed out; the clock keeps running and reconnecting restores them.
