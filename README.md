# playren

ブラウザで使える連珠の対局所。  
合言葉で同じ部屋に入り、2 人対局またはペア連珠で対局。他の参加者は観戦可。

## 対局の流れ

1. 入室する
  表示名と合言葉を入力して入室。合言葉が同じなら同じ部屋に接続。
2. 席に着く
  空いている席をクリックして着席。観戦席へ戻るときは観戦席エリアをクリック。
3. 準備 OK を押す
  全員が自席をクリックして準備 OK にすると、自動で対局開始。
4. 開局（Taraguchi-10）
  開局は Taraguchi-10。途中で Swap や、黒の 10 題提示の分岐あり。
5. 対局を進める
  着手すると持ち時間が加算（フィッシャールール）。
6. 終局・局後検討
  時間切れ、終局、満局合意で対局終了。終了後は局後検討モードで手順を前後可。2 局目以降は、黒白が自動で入れ替わり。

## 部屋の設定

非対局時、誰でも変更可。変更すると参加者全員にお知らせが流れる。

- 時間設定（基本分 + 秒加算）
- 手番の色交換
- ペア連珠の ON/OFF
- 対局席リセット（全員が観戦席に移動）



## 対局中の操作

- 満局提案、待った、終局
- 局面ナビゲーション（`<<`, `<`, `最新`, `>`, `>>`、矢印キー対応）
- 最終手の確認（`最新` ボタンを押すと、最終手が一時的に光る）
- チャット
- 着手確認（ON にすると、2 回クリックで着手）



## 表示のカスタマイズ

目メニュー（画面右下）から変更可。設定は端末に保存。

- 言語（日本語 / English / 中文）
- 配色（ライト / グレー / ダーク）
- 効果音 ON/OFF
- 座標表示・手数表示の ON/OFF
- 盤面色（薄茶・茶・緑・紫・灰・白）、石の陰影



## その他
