# playren

ブラウザで使える連珠の対局所。  
合言葉で同じ部屋に入り、2 人対局またはペア連珠で対局。他の参加者は観戦可。

## 対局の流れ

1. 入室する
  合言葉が同じなら同じ部屋に接続
2. 席に着く
  空席をタップして着席、観戦席エリアをタップで退席
3. 準備 OK する
  自席をタップして準備 OK。全員 OK で対局開始
4. 対局を進める
  開局は Taraguchi-10。着手すると持ち時間が加算（フィッシャールール）
5. 終局・局後検討
  終局、満局合意、時間切れで対局終了。終了後は局後検討

## 部屋の設定

非対局時、誰でも変更可。変更すると参加者全員にお知らせが流れる。

- ペア連珠の ON/OFF
- 途中開始の ON/OFF（検討盤面から対局開始。6 手目以降で有効）
- 棋譜の読込み（RenjuPortal の URL または棋譜テキストを、検討盤面へ反映）
- 先後交換（手動で交換しない場合、黒白が交互に自動設定される）
- 時間設定（基本分 + 秒加算）
- 対局席リセット（全員が観戦席に移動）



## 対局中の操作

- 満局提案、待った、終局
- 局面ナビゲーション（`<<`, `<`, `最新`, `>`, `>>`、矢印キー対応）
- 最終手の確認（`最新` ボタンを押すと、最終手が一時的に光る）
- チャット
- 着手確認（ON にすると、2 回タップで着手）



## 表示のカスタマイズ

目メニュー（画面右下）から変更可。設定は端末に保存。

- 言語、配色
- 効果音 ON/OFF
- 座標表示・手数表示の ON/OFF
- 最終手の強調表示 ON/OFF
- 盤面色、石の陰影

## 棋譜のプライバシーについて

Playrenでは、対局者以外が対局終了後の棋譜を検索・閲覧する機能は提供していません。
製作者が対局内容を確認するための機能もありません。
