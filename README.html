playren

ブラウザで使える Renju（連珠）対局所です。合言葉で同じ部屋に入り、通常の 2 人対局または 4 人のペア連珠で遊べます。他の参加者は観戦できます。

対局の流れ

  1. 入室する
    表示名と合言葉を入力して入室します。合言葉が同じなら同じ部屋に接続されます。
  2. 席に着く
    空いている席をクリックして着席します。ペア連珠では左右それぞれ上下 2 席になります。観戦席へ戻るときは観戦席エリアをクリックします。
  3. 準備 OK にする
    着席した全員がそれぞれ自分の席をクリックして準備 OK にすると、自動で対局が始まります。
  4. 開局（Taraguchi-10）
    開局は Taraguchi-10 進行です。途中で Swap 選択や、黒の Choice（10 題提示）分岐があります。
  5. 対局を進める
    着手すると持ち時間が加算されます（フィッシャールール）。
  6. 終局・局後検討
    時間切れ、終局、満局合意で対局終了。終了後は局後検討モードで手順を前後でき、チャットの終局メッセージから終局図の RenjuPortal 棋譜リンクをコピーできます。2 局目以降は、対局開始時に黒白が自動で入れ替わります。

部屋の設定

非対局時なら誰でも変更できます。変更すると参加者全員にお知らせが流れます。

  • 時間設定（基本分 + 秒加算、時間ハンデ対応）
  • 手番の色交換
  • ペア連珠の ON/OFF
  • 対局席リセット（全員が観戦席に移動）

対局中の操作

  • 満局提案、待った、終局
  • 局面ナビゲーション（<<, <, 最新, >, >>、矢印キー対応）
  • チャット（コメント投稿）
  • 着手確認（ON にすると、対局時・検討時に 1 回目で候補枠、2 回目で着手します）

表示のカスタマイズ

目メニュー（画面右下）から変更できます。設定は端末に保存されます。

  • 言語（日本語 / English / 中文）
  • 配色（自動 = OS 設定に追従 / ライト / ダーク）
  • 効果音 ON/OFF
  • 座標表示・手数表示の ON/OFF
  • 盤面色（茶・緑・紫・灰・白）、石の陰影

その他

  • 局後検討と棋譜コピーは終局後のみ使えます
  • 再接続対応（切断すると名前がグレー表示。持ち時間は進行し続け、復帰で元に戻ります）
  • スマホでは「ホーム画面に追加」すると、アプリとして起動できます
