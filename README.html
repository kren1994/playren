playren

ブラウザで使える Renju（連珠）対局所です。合言葉で同じ部屋に入り、通常の 2 人対局または 4 人のペア連珠で遊べます。他の参加者は観戦できます。

対局の流れ

  1. 入室する
    表示名と合言葉を入力して入室します。合言葉が同じなら同じ部屋に接続されます。
  2. 席に着く
    空いている席をクリックして着席します。ペア連珠では左右それぞれ上下 2 席になります。観戦席へ戻るときは観戦席エリアをクリックします。
  3. 準備 OK にする
    着席した全員がそれぞれ自分の席をクリックして準備 OK にすると、自動で対局が始まります。
  4. 開局（Taraguchi-10）
    開局は Taraguchi-10 進行です。途中で Swap 選択や、黒の Choice（10 題提示）分岐があります。
  5. 対局を進める
    着手すると持ち時間が加算されます（フィッシャールール）。
  6. 終局・局後検討
    時間切れ、時間内に復帰なし、終局、満局合意で対局終了。終了後は局後検討モードで手順を前後でき、チャットの終局メッセージから終局図の RenjuPortal 棋譜リンクをコピーできます。

主な機能

  • 2 人対局 / 4 人のペア連珠 + 観戦席
  • 名前に下線が付いている人はホスト
  • ホストは以下の権限をもつ
    • 時間設定（基本分 + 秒加算、時間ハンデ対応）
    • 非対局時の色交換
    • ペア連珠の ON/OFF
  • チャット（入退室ログ / コメント投稿）
  • 満局提案、待った、終局
  • 局面ナビゲーション（<<, <, 最新, >, >>、矢印キー対応）
  • 局後検討（終局後のみ）
  • 棋譜コピー（終局後のみ、チャットの終局メッセージから RenjuPortal の終局図リンクをコピー）
  • 表示設定（言語切替、効果音 ON/OFF、座標表示 ON/OFF、盤面色切替、手数表示 ON/OFF）
  • 着手確認（ON にすると、対局時・検討時に 1 回目で候補枠、2 回目で着手します）
  • 再接続対応（切断時は一時停止して復帰待機。同じ表示名・同じ合言葉で復帰でき、一定時間復帰できない場合は終局）
