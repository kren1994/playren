playren

playren 是可在浏览器中使用的 Renju（连珠）对局室，支持普通 2 人对局或 4 人搭档连珠，其他参与者可以观战。

对局流程

  1. 进入房间
    输入昵称和口令后进入房间。口令相同的人会连接到同一个房间。
  2. 入座
    点击空着的座位入座。搭档连珠模式下左右两队各有上下两个座位。点击观战席区域可返回观战席。
  3. 准备完毕
    所有入座者分别点击自己的座位完成准备后，对局会自动开始。
  4. 开局（Taraguchi-10）
    开局按 Taraguchi-10 进行。过程中会出现 Swap 选择，以及黑方 Choice（10 题提示）分支。
  5. 进行对局
    每次落子后会增加持有时间（Fischer 规则）。
  6. 终局与复盘
    时间耗尽、终局、同意和棋时，对局结束。结束后可以进入复盘模式前后查看手顺，也可以从聊天中的终局消息复制 RenjuPortal 的终局图棋谱链接。

主要功能

  • 2 人对局 / 4 人搭档连珠 + 观战席
  • 名字带下划线的玩家是主机
  • 主机拥有以下权限
    • 设置持有时间（基本分钟 + 每手加秒，支持时间让子）
    • 非对局时交换颜色
    • 开启或关闭搭档连珠
  • 聊天（评论投稿）
  • 提和、悔棋、终局
  • 局面导航（<<, <, 最新, >, >>，支持方向键）
  • 复盘（仅终局后）
  • 复制棋谱（仅终局后，从聊天中的终局消息复制 RenjuPortal 的终局图链接）
  • 显示设置（语言切换、音效 ON/OFF、坐标显示 ON/OFF、棋盘色切换、手数显示 ON/OFF）
  • 落子确认（开启后，第一次点击显示候选圆框，第二次点击才落子）
  • 重连支持（断线时名字变灰，用时照常进行，重连后恢复）
