playren

浏览器连珠对局室。相同暗号进入同一房间，2 人对局或配对连珠。其余参与者可观战。

对局流程

  1. 进入房间
    口令相同即可连接到同一房间。
  2. 入座
    点击空位入座。点击观战区返回观战席。
  3. 准备完毕
    全员点击自席准备完毕后，对局自动开始。
  4. 进行对局
    采用 Taraguchi-10 开局；每次落子增加持时（菲舍尔规则）。
  5. 终局・复盘
    认输、和棋合意或超时后对局结束；结束后可复盘。

房间设置

非对局时任何人可修改。修改后通知全员。

  • 时间设置（基础分钟 + 秒加算）
  • 交换执棋颜色（未手动交换时，黑白会自动交替设置）
  • 配对连珠 开/关
  • 中途开局 开/关（从复盘局面开始；第 6 手及以后有效）
  • 重置座位（所有人回到观战席）

对局中的操作

  • 提议和棋、悔棋、终局
  • 局面导航（<<, <, 最新, >, >>，支持方向键）
  • 查找最后一手（按「最新」短暂高亮最后一手）
  • 聊天
  • 落子确认（开启后，两次点击落子）

显示自定义

眼睛菜单（右下）可修改。设置保存在本机。

  • 语言、配色
  • 音效 开/关
  • 坐标显示・手数显示 开/关
  • 最后一手高亮显示 开/关
  • 棋盘颜色、棋子阴影

棋谱隐私

Playren 不提供让对局者以外的人搜索或查看对局结束后棋谱的功能。
也不提供让制作者查看对局内容的功能。

其他

  • 断线重连（断线者名字变灰，持时继续）
  • 手机「添加到主屏幕」可像 App 一样启动
